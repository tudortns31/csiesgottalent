# CSIE's Got Talent

Website and event registration project for CSIE's Got Talent.

## Project structure

- `index.html` and `styles.css` — event website
- `poze/` — website images
- `front-end-formular/` — registration form
- `cyber-stars/` — Node.js backend source and package manifest

The SQLite database is included as requested. Do not put real registration data in a public repository.

## GitHub Pages

The site can be published from the repository root using GitHub Pages. The registration backend requires separate hosting; GitHub Pages only serves static files.
